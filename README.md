# Aplicación Móvil 100% en Python para Automatización del Formato SASA-01 (v2)

Sistema completo en Python (Flask + ReportLab) con interfaz móvil táctil, captura de firma autógrafa, respaldo offline, historial con buscador para reimpresión de PDFs y exportación directa a Excel/CSV.

## Instalación y Uso
1. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Inicia el servidor:
   ```bash
   python app.py
   ```
3. Accede desde el teléfono mediante la IP local de tu servidor (ej. `http://192.168.1.100:5000`).
